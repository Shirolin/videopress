# Videopress 产品宣传片分镜与节奏表

## 全局规格

| 项目 | 参数 |
| --- | --- |
| 分辨率 | 1920 × 1080（`Scale = 1`，1 DIP = 1 像素） |
| 帧率 | 30 fps |
| 总时长 | 26.0 秒（`TotalFrames = 780`） |
| 音乐节拍 | 120 BPM（1 拍 = 15 帧 = 0.5 秒；1 小节 = 60 帧 = 2.0 秒） |
| 音频格式 | 48 kHz 立体声（`float32` 交错采样，AAC 192 kb/s 编码） |
| 场景转场 | 12 帧（0.4 秒）平滑叠化（`CrossfadeFrames = 12`） |
| 默认输出 | `dist/promo/videopress-promo.mp4` |

## 视觉基调（严格对齐 `docs/DESIGN.md`）

- **色彩体系**：全部直接取自 MujicaUI `theme.Dark()` 与 `theme.Light()`，不自建色板、不写内联 hex。
  - 深色深炭：背景 `#191618`、卡片面 `#242024`、边框 `#51424A`、主文 `#F2EBDD`、辅文 `#BCAEAA`、酒红强调 `#9C3C53` / `#E4A0AE`、金饰线 `#BDA172`、成功绿 `#94C6A4`。
  - 浅色象牙：背景 `#F2EBDD`、卡片面 `#FBF7EF`、边框 `#D2C3AF`、主文 `#211C1D`、辅文 `#6A5B55`、酒红强调 `#7D2034`、金饰线 `#AD9164`、成功绿 `#326247`。
- **排印体系**：衬线标题（`Georgia` + 中文衬线回退 `Noto Serif SC / STSong / SimSun`）配清晰无衬线正文（`Segoe UI` + `Microsoft YaHei UI / Microsoft YaHei`）与等宽代码字体（`Cascadia Mono / Consolas`）。
- **克制原则**：
  - 禁止紫/品红光球、毛玻璃、霓虹渐变边框或渐变按钮。
  - 禁止 Sparkles / Rocket / PartyPopper 类装饰图标、英文全大写字距装饰。
  - 禁止推销话术（高颜值 / 高速 / 智能 / 专业级 / 闪电 / 极速），所有文案只陈述真实功能与指标。
  - 动效仅服务于信息进场、状态切换与焦点引导，保持简洁利落的阻尼与缓动。

## 逐幕详细导演说明

### 第 1 幕：品牌开场与核心定位（Frames `0..120`，局部 `0..120`）
- **叙事目标**：建立克制、沉稳、面向 Windows 桌面的原生工具气质。
- **画面结构**：
  - `0..12`：深炭画布与极细编辑网格边线渐显。
  - `12..42`（对齐 `CueBrandReveal = 12`）：居中呈现 `resources/icon.png`（圆角柔和阴影）与衬线字标 `Videopress`，下方酒红 + 暖金细线水平展开。
  - `32..68`：副标题 `面向 Windows 的原生视频压缩工具` 轻柔上移显现。
  - `54..96`：底部三枚等距能力标签依次入场：`纯 Go 原生界面`、`FFmpeg 编码引擎`、`GUI 与 CLI 双入口`。
  - `108..120`：整体平滑叠化退出至第 2 幕。

### 第 2 幕：拖拽与批量压缩工作区（Frames `108..255`，局部 `0..147`）
- **叙事目标**：用真实界面截图展示零记忆参数的日常批量压缩体验。
- **画面结构**（左文 40% / 右图 60%，四周留白 ≥ 80px）：
  - 左侧编辑栏：
    - 栏目标签：`01 · 批量工作区`
    - 衬线标题：`拖入即压，` / `队列进度清晰可控`
    - 简明要点：三档预设（`小文件 / 标准 / 高画质`）、默认输出至同目录 `compressed/`、实时速率与预计剩余时间、支持逐文件取消与状态筛选。
    - 真实数据指标卡片（与 `workspace-dark.png` 一致）：`241.0 MB` 已节省空间、`73.5%` 整体节省率（衬线数字，绿色成功色）。
  - 右侧实机展示框：
    - 局部 `0..66`：真实截图 `docs/screenshots/workspace-dark.png`（900×820 比例保持）稳健落位并附轻微平滑推进。
    - 局部 `66..84`（对齐 `CueWorkspaceSwap = 174`）：框内平滑交叉溶解至 `docs/screenshots/batch-progress.png`，突出展示 73% 整体进度条与跳过/失败/处理中状态。
    - 右下方简洁标注条提示当前状态：`默认写入 compressed/ · 自动记录 compress_summary.log`。
  - `135..147`：整体平滑叠化退出。

### 第 3 幕：GPU 硬件加速与并发队列（Frames `243..390`，局部 `0..147`）
- **叙事目标**：可视化呈现核心引擎优势——自动探测硬件编码器 + Worker Pool 多文件并发。
- **画面结构**（居中三栏工作流架构图，宽 1680px）：
  - 顶部标题区：`02 · 硬件加速与并发` + 衬线主标 `自动探测显卡硬编，多文件并发压缩`。
  - 中部三段管线（左 → 中 → 右，细线条连接）：
    1. **输入队列卡片**：列出 4 个典型任务（`holiday.mp4`、`long-webinar.mkv`、`demo.mp4`、`capture_4k.mov`）与体积标注。
    2. **Worker Pool 并发池（`-c 3`）**：3 条并行 Worker 轨道，局部帧 `24..108` 动态推进进度条与实时倍速（`2.4x` / `3.1x` / `2.8x`），在局部帧 `93`（对齐 `CueWorkerComplete = 336`）完成状态切为绿色勾选与节省率摘要。
    3. **GPU 编码器探测卡片**：三行编码器状态项——`NVIDIA  h264_nvenc`（酒红高亮「已探测并启用」）、`Intel  h264_qsv`、`AMD  h264_amf`，底部说明栏注明「未检测到硬编时自动回退 CPU 编码」。
  - 底部特性条：3 个紧凑平铺指标卡：`可调并发数 (Worker Pool)`、`音频流直通 (--copy-audio)`、`压缩摘要自动归档`。
  - `135..147`：平滑叠化过渡到象牙浅色第 4 幕。

### 第 4 幕：动图导出与几何裁剪（Frames `378..525`，局部 `0..147`）
- **叙事目标**：切至象牙浅色画布形成视觉呼吸感，展示动图多格式导出与可选几何裁剪。
- **画面结构**（左图 52% / 右文与裁剪图解 48%，使用 `theme.Light()`）：
  - 左侧实机视口：固定比例窗口裁剪容器（静态 `Clip()`），内部加载 `docs/screenshots/gif-custom.png`（900×1250），在局部帧 `16..96` 平滑向上滚动，从主工作区自然聚焦至底部的「动图导出」自定义面板（起始时间、时长、宽度、帧率、体积目标、WebP 质量）。
  - 右侧双模块：
    - 上半部：`03 · 动图与裁剪` + 衬线标题 `多格式动图导出，` / `支持压缩前几何裁剪`。
      - 格式标签：`GIF` · `APNG` · `WebP`；档位条：`流畅 / 均衡 / 高清 / 自定义`。
    - 下半部：**几何裁剪可视化卡片**（象牙表面卡片）：
      - 展示原始画幅外框与内部动画收缩定格的酒红裁切线（在局部帧 `78`，对齐 `CueCropLock = 456` 定格），标注去黑边/安全边示意。
      - 下方两行等宽参数示例：`--crop-center 16:9 --crop-scale 0.9` 与 `--crop 1600:900:160:90`，注记「裁剪在缩放前执行，默认不裁」。
  - `135..147`：平滑叠化切回深炭第 5 幕。

### 第 5 幕：CLI 双入口与 Windows 系统集成（Frames `513..651`，局部 `0..138`）
- **叙事目标**：展示终端效率工作流与免管理员权限的 Windows 系统集成。
- **画面结构**（左终端 56% / 右系统集成 44%，深炭主题）：
  - 顶部标题区：`04 · 双入口与系统集成` + 衬线主标 `桌面与终端同源，融入 Windows 日常操作`。
  - 左侧终端窗口（使用 `WindowFrame` + 等宽字体）：
    - 局部 `10..42`：打字机式键入命令 `> videopress --preset standard --hw -c 3 *.mp4 *.mkv`。
    - 局部 `42..81`：显示平滑无闪烁并发状态行与总进度条推进。
    - 局部 `81..126`（对齐 `CueCLISummary = 594`）：输出整齐的压缩率摘要表（`holiday.mp4` 240.0 MB → 46.0 MB `-80.8%`、`long-webinar.mkv` 128.4 MB → 38.2 MB `-70.2%`、`demo.mp4` 88.0 MB → 41.0 MB `-53.4%`）。
    - 终端底栏附注：`--skip-existing` · `--force` · `--install-path`。
  - 右侧 Windows 集成区（上下两张卡片）：
    - 上卡片：**模拟资源管理器右键菜单**，高亮酒红选中项 `使用 Videopress 压缩`，配简短说明「多选文件自动合并到单一实例窗口」。
    - 下卡片：**系统集成开关一览**，展示 4 项开关状态：`资源管理器右键菜单`、`发送到 (SendTo)`、`用户 Path 环境变量`、`中英双语菜单热切换`，底部注记「仅写入当前用户，无需管理员权限」。
  - `126..138`：平滑叠化至第 6 幕。

### 第 6 幕：明暗主题切换与结尾收束（Frames `639..780`，局部 `0..141`）
- **叙事目标**：呼应深炭/象牙双主题外观与中英双语能力，然后干净收束至品牌尾板。
- **画面结构（两段式）**：
  - **前段（局部 `0..72`）明暗主题双视图**：
    - 画面左右平滑呈现深色工作区（`workspace-dark.png`）与浅色外观设置页（`appearance-light.png`），中间由竖向暖金细线分隔，上方简洁标题 `深炭与象牙，默认跟随系统明暗`，下方三枚说明胶囊：`跟随系统 / 浅色 / 深色`、`中英双语切换`、`单文件便携与安装包`。
    - 局部 `58..72`：前段干净淡出，同时深炭尾板背景就位。
  - **后段（局部 `66..141`，对齐 `CueFinaleLock = 708`）品牌收束尾板**：
    - 居中呈现 `resources/icon.png` + `Videopress` 大号衬线字标 + 酒红/暖金细线。
    - 核心收束句：`Windows 原生视频压缩工具 · GUI 与 CLI 双入口`。
    - 底部技术与开源信息行：`Go + MyGO + MujicaUI` · `FFmpeg` · `MIT License` · `github.com/Shirolin/videopress`。
    - 局部 `100..141` 稳态停留展示，画面保持清晰无抖动直至结束。
